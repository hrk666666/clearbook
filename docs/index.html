为什么选择 Clear Book？

从广告清理到格式转换，一站式解决 TXT 电子书的所有"脏数据"问题。

campaign

广告 & 推广清理

一键去除网址、推广话术、站点水印、翻页提示、引导语。覆盖主流小说网站的广告模式。

psychology

智能同音字检测

拼音相似度 + 上下文感知 + 模式识别。自动识别"威信→微信"、"某宝→淘宝"等混淆写法。

swap_horiz

格式转换

EPUB / HTML / PDF → TXT。HTML 类格式自动去除脚本、样式、导航等非正文内容。

tune

精细规则控制

每条规则独立开关，支持自定义正则表达式。全开/全关一键切换，灵活组合。

store

规则市场

基于 GitHub 的社区规则仓库。浏览、安装、创建、分享规则包，持续扩展清洗能力。

smart_toy

AI 规则生成

复制提示词发给 ChatGPT / Claude，AI 分析你的 TXT 文件后返回精准清洗规则。

compress

智能压缩

去除多余空行、合并短段落、去重重复章节。让文件更紧凑，阅读更流畅。

preview

实时对比预览

左右对照显示原文与清洗结果，自动定位首个差异位置。清洗前后一目了然。

code

纯离线运行

所有资源内嵌，无需网络。你的数据永远留在本地，隐私安全有保障。
